# Hey Listen!

Olá, Percio aqui (aka sr00t3d) 👋
**Linux SysAdmin | Infrastructure | Cybersecurity | DevSecOps | Automation**

Administrador de Sistemas Linux com mais de 10 anos de experiência em infraestrutura, sustentação de ambientes críticos, troubleshooting avançado, automação e segurança.

Minha trajetória foi construída principalmente em ambientes de infraestrutura web e hospedagem, passando por suporte técnico N2/N3, administração de servidores Linux, troubleshooting de ambientes críticos, migrações, automação e segurança.

Nos últimos anos, venho direcionando essa experiência para Cybersecurity e DevSecOps, com foco em segurança de sistemas Linux, hardening, resposta a incidentes, segurança de pipelines, containers, automação e integração de ferramentas de segurança.

Também desenvolvo projetos próprios que combinam infraestrutura, segurança, desenvolvimento e automação, utilizando programação como ferramenta para resolver problemas operacionais e construir soluções técnicas.
